# راهنمای خروجی گرفتن — EXE ویندوز و APK اندروید

## نسخه‌ی ویندوز چطور کار می‌کند؟
فایل EXE **همه‌چیز را داخل خودش دارد**: برنامه + سرور + دیتابیس داخلی.
نصب می‌کنی → اجرا می‌کنی → کار می‌کند. **نه Docker لازم است، نه اینترنت.**

- داده‌هایت اینجا ذخیره می‌شود: `%APPDATA%\planner-desktop\data` (با آپدیت برنامه پاک نمی‌شود)
- اگر بعداً سرور اینترنتی راه انداختی: داخل برنامه **Ctrl + ,** → «اتصال به سرور» → آدرس را بده.
  همان EXE به حالت آنلاین می‌رود و با گوشی هماهنگ می‌شود.
- از بخش **تنظیمات → داده‌ها** می‌توانی پشتیبان بگیری و در سرور بازیابی کنی.

## الف) ساخت EXE ویندوز — یک دوبار کلیک
پیش‌نیاز: Node.js (LTS از nodejs.org).

1. روی **`build-exe-windows.bat`** دوبار کلیک کن.
2. مراحل: نصب پکیج‌ها (بار اول) → بیلد برنامه → بسته‌بندی سرور → دانلود Electron (بار اول) → ساخت نصب‌کننده.
   بار اول ۵ تا ۱۵ دقیقه، دفعات بعد ۲ تا ۴ دقیقه.
3. پوشه‌ی `packaging\electron\dist` باز می‌شود:
   - **`Planner-1.1.0-win-x64.exe`** → نصب‌کننده (آیکون روی دسکتاپ و منوی Start)
   - **`Planner-1.1.0-portable.exe`** → بدون نصب (حتی روی فلش)
4. نصب کن و از منوی Start «Planner» را باز کن. بار اول چند ثانیه «در حال راه‌اندازی…» نشان می‌دهد.

**آپدیت به نسخه‌ی جدید:** پروژه‌ی جدید را دانلود کن → دوباره `build-exe-windows.bat` → نصب روی نسخه‌ی قبلی. داده‌ها می‌مانند.

**خطاهای رایج**
- ویندوز هنگام اجرا هشدار آبی SmartScreen داد → **More info → Run anyway** (امضای دیجیتال نداریم؛ طبیعی است).
- پنجره‌ی سیاه فوراً بسته شد → از PowerShell اجرا کن تا پیام بماند: `.\build-exe-windows.bat`
- دانلود گیر کرد → VPN را روشن کن و دوباره بزن (اسکریپت از mirror هم استفاده می‌کند).
- برنامه باز شد ولی «راه‌اندازی ناموفق» گفت → در همان صفحه روی «فایل لاگ» کلیک کن و متنش را بفرست.

## ب) APK اندروید — آفلاین، داده‌ها داخل خود گوشی

اپ اندروید **هیچ سروری لازم ندارد**: یک دیتابیس PostgreSQL کوچک (PGlite) داخل خود اپ اجرا می‌شود و
داده‌ها در حافظه‌ی گوشی می‌ماند. اولین باز شدن ۲ تا ۴ ثانیه «در حال بارگذاری…» دارد (راه‌اندازی موتور دیتابیس).

- داده‌های گوشی و کامپیوتر **جدا** هستند. برای انتقال: **تنظیمات → داده‌ها → پشتیبان‌گیری** در یکی، **بازیابی** در دیگری.
- اگر بعداً خواستی گوشی به سرور وصل شود (مثلاً به برنامه‌ی ویندوز در وای‌فای خانه یا سرور اینترنتی):
  داخل اپ **تنظیمات → «اتصال به سرور (اختیاری)»**. برای برگشت به حالت آفلاین: در سرور، تنظیمات → «تغییر آدرس سرور».
- داده‌ها با حذف اپ (یا «Clear data») پاک می‌شوند — هر چند وقت یک‌بار پشتیبان بگیر.

### ساخت APK — راه ۱: در ابر، بدون نصب هیچ‌چیز (پیشنهادی)
1. یک حساب رایگان در <https://github.com> بساز و یک repository جدید (private) بساز.
2. پروژه را آپلود کن: **Add file → Upload files** → کل پوشه‌ی پروژه را بکش و رها کن
   (پوشه‌های `node_modules`، `.next`، `.next-mobile`، `packaging\electron\node_modules`، `packaging\electron\server` و `dist` را **نفرست**) → **Commit**.
3. تب **Actions** → سمت چپ **Android APK** → **Run workflow** → **Run**.
4. حدود ۱۰ دقیقه بعد → روی اجرای سبز کلیک کن → پایین صفحه **Artifacts → Planner-apk** → دانلود → zip را باز کن → **`Planner.apk`**
5. فایل را با تلگرام/کابل به گوشی بفرست و نصب کن (اجازه‌ی «نصب از منابع ناشناس»).

دفعات بعد فقط فایل‌های تغییرکرده را آپلود کن؛ هر Commit روی `src/` خودش APK جدید می‌سازد.

### ساخت APK — راه ۲: روی کامپیوتر خودت (نیاز به Android Studio)
1. [Android Studio](https://developer.android.com/studio) را نصب کن و یک بار بازش کن تا SDK را دانلود کند (ممکن است VPN لازم باشد).
2. روی **`build-android-windows.bat`** دوبار کلیک کن (بار اول Gradle حدود ۵۰۰ مگابایت دانلود می‌کند).
3. خروجی: **`packaging\android-output\Planner.apk`** → به گوشی بفرست و نصب کن.
   اگر SDK پیدا نشد، اسکریپت Android Studio را باز می‌کند: **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.

### نکته‌های فنی (برای توسعه)
- بیلد موبایل: `PLANNER_TARGET=mobile npx next build` → خروجی استاتیک در `.next-mobile/`؛ `packaging/capacitor/prepare.js` آن را با موتور PGlite در `www/` می‌چیند.
- منطق برنامه در `src/server/services.ts` مشترک است؛ روی سرور از طریق `src/app/api/*` و روی گوشی از طریق `src/local/transport.ts` اجرا می‌شود.
- اگر جدول جدیدی به `src/db/schema.ts` اضافه کردی، `src/db/bootstrap.ts` را هم به‌روز کن (گوشی جداول را از آن می‌سازد).

## ج) سرور اینترنتی (برای همگام‌سازی همه‌ی دستگاه‌ها)
یک VPS لینوکس + دامنه:
```bash
curl -fsSL https://get.docker.com | sh
cd planner && cp .env.production.example .env.production && nano .env.production   # رمز + DOMAIN
docker compose --profile https --env-file .env.production up -d --build
```
بعد در EXE: **Ctrl + ,** → «اتصال به سرور» → `https://your-domain.com`. برای اندروید هم همین آدرس.
داده‌های محلی را با «تنظیمات → داده‌ها → پشتیبان‌گیری» بگیر و در سرور «بازیابی» کن.

## سوالات رایج
- **داده‌های EXE کجاست؟** `%APPDATA%\planner-desktop\data` — در صفحه‌ی Ctrl + , دکمه‌ی «پوشه‌ی داده‌ها» هست.
- **Docker دیگر لازم نیست؟** نه — ویندوز و اندروید هر دو مستقل و آفلاین کار می‌کنند. Docker فقط برای سرور اینترنتی (همگام‌سازی) است.
- **گوشی و کامپیوتر هم‌زمان یک داده را ببینند؟** یا هر دو را به یک سرور وصل کن (برنامه‌ی ویندوز با Ctrl + , می‌تواند سرور باشد)، یا با پشتیبان‌گیری/بازیابی جابه‌جا کن.
- **APK نصب نشد («App not installed»)؟** نسخه‌ی قبلی با امضای دیگری نصب شده؛ اول آن را حذف کن.
- **جداول دیتابیس را تغییر دادم؟** `src/db/schema.ts` و `src/db/bootstrap.ts` را هر دو به‌روز کن.
- **iOS؟** همان Capacitor: `npx cap add ios` روی مک با Xcode.
